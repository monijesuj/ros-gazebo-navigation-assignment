# Условия задания → реализация и доказательства

**Язык / Language:** Русский · [English](REQUIREMENTS.md) · [Главная страница](README.ru.md)

Таблица относится к предоставленному заданию «Программист робота (ROS/Gazebo)». Альтернативы роботов, ROS и симуляторов означают выбор, а не обязательную реализацию каждого стека. Здесь выбраны **ROS 2 Humble + Gazebo Fortress (Ignition)**; дополнительно доступны три робота и три мира.

| Условие | Статус | Как и где проверить |
| --- | --- | --- |
| Автономный проезд A → B с объездом препятствий | Реализован; измерен для каждой комбинации | `navigation.py`, `planning.py`; [отчёты запусков](evidence/matrix), видео |
| Робот: TurtleBot3, Jackal или собственный URDF/Xacro | Все три доступны на выбор | `./run.sh robot:=jackal` (также `custom`, `turtlebot3`); зафиксированные описания и меши в `assets/`; тот же URDF преобразуется в SDF |
| 2D-лидар **или** ультразвуковые дальномеры | 2D-лидар на каждом роботе | `assets.py`, `/scan`, `mapping.py`, `safety.py`; счётчики сообщений и карты |
| Камера глубины, имитирующая Orbbec Astra | RGB-D на каждом роботе | Нативный `rgbd_camera`; `/camera/depth_image`, RGB, калибровка и точки; разбор глубины/контроль скорости, RGB в RViz |
| GPS | Реализован нативный эквивалент Fortress | `NavSat` + `ros_gz_bridge` → `/gps/fix`; `localization.py`, преобразование GPS-точек |
| Указанный `gazebo_ros_gps` | Различие платформ явно раскрыто | Плагин Classic нельзя загрузить в Fortress. Разрешённый вариант Ignition использует нативный NavSat; README прямо описывает замену |
| ROS 1 Noetic **или** ROS 2 Humble | ROS 2 Humble | `package.xml`, launch; Ubuntu 22.04, Dockerfile |
| Gazebo Classic **или** Ignition | Gazebo Fortress / Ignition 6 | `ign gazebo`, нативные системы, выбор версии в README |
| Плоская поверхность со статическими препятствиями | Три локальных мира на выбор | `config/{obstacle_course,warehouse,outdoor}.json`, `assets.py`; без загрузки внешних моделей мира |
| Обозначенные старт и финиш | Зелёная A, синяя B | Генерация SDF; видео и снимок окон симуляции |
| Waypoints в GPS- или мировых координатах | Оба режима, последовательные списки | `waypoint_mode`, `waypoints_gps`, `waypoints_world`; тесты ENU, реализация миссии |
| Узлы, топики, tf, launch-файлы ROS | Интегрированы и описаны | `launch/demo.launch.py`; таблицы топиков/TF в [README](README.ru.md); map/odom/base/датчики, отдельные мосты |
| Python или C++ | Python | Пакет Ament Python; алгоритмы выделены для тестирования |
| Узлы чтения данных датчиков | Мосты и потребители | Мосты лидара, камеры, GPS, IMU; локализатор/карта/контроль скорости читают реальные потоки симулятора |
| Построение карты **или** SLAM | Карта занятости по датчикам | Изначально неизвестная карта, очистка лучами, логарифмические отношения шансов в `sensing.py` / `mapping.py`; геометрия препятствий заранее не передаётся узлам управления |
| Планирование и управление | A* + следование точкам + отдельный контроль скорости | `planning.py`, `navigation.py`, `safety.py`; тесты выхода из уменьшенного запаса и проверок столкновений |
| Следование GPS-точкам | Основная миссия использует географическую цель | ENU WGS84 + коррекция колёсного движения по GPS + направление IMU; число GPS-сообщений, фактическая ошибка финиша |
| Nav2/gmapping/amcl/move_base | Необязательны; выбраны собственные алгоритмы | [DESIGN.ru.md](DESIGN.ru.md) объясняет настройки и ограничения; зависимость от Nav2 не заявлена |
| Видео Gazebo + RViz длительностью 1–3 минуты | Приложено к релизу | `evidence/demo.mp4`, `demo.json`; реальный захват окон, подписи из текущего отчёта |
| ROS bag | Необязателен; приложен к релизу | Архив bag с датчиками/TF/картой/путями/командами/состоянием/безопасностью и записанной проверкой |
| Git-репозиторий | Предоставлен | Закрытый GitHub-репозиторий; отдельный zip-архив; проверяющему нужен доступ либо архив |
| README: зависимости, описание, команда запуска | Предоставлен | Полные [русский](README.ru.md) и [английский](README.md) README; скрипт зависимостей, запуск одной командой, Docker |
| Модель + датчики (2 балла) | Доказательства для всех моделей | Сгенерированные URDF/SDF, топики датчиков, запуски ROS/RViz/Gazebo |
| Мир (1 балл) | Доказательства для всех миров | Статические препятствия, отмеченные A/B, отчёты запусков |
| Интеграция ROS (2 балла) | Доказательства предоставлены | Узлы, launch, часы, мосты, QoS, владельцы TF описаны |
| Навигация (3 балла) | Измерения без самостоятельного присвоения баллов | Истинная ошибка цели, отсутствие касаний, зазор, потоки данных, конечная остановка; [VALIDATION.ru.md](VALIDATION.ru.md) |
| GPS (1 балл) | Продемонстрирован и проверен | GPS-локализация/следование, тесты ENU |
| Качество (1 балл) | Материалы для проверки предоставлены | Модульный код, форматирование/линтер, тесты, лицензии, [DESIGN.ru.md](DESIGN.ru.md), явные ограничения |
| Воспроизводимость (1 балл) | Контейнер и автоматические проверки | Dockerfile, шаблон CI, скрипты, сохранённые результаты чистого контейнера |
| Интерфейсы датчиков Raspberry Pi 5 (бонус) | Ответ предоставлен | [ELECTRONICS.ru.md, раздел 1](ELECTRONICS.ru.md#1-подключение-датчиков) |
| Питание от одного аккумулятора (бонус) | Ответ предоставлен | [ELECTRONICS.ru.md, раздел 2](ELECTRONICS.ru.md#2-питание-системы-от-одного-аккумулятора) |
| Проверка датчиков без ROS (бонус) | Ответ предоставлен | [ELECTRONICS.ru.md, раздел 3](ELECTRONICS.ru.md#3-проверка-без-ros) |
| Кандидат понимает настройки | Требует подготовки кандидата | [DESIGN.ru.md](DESIGN.ru.md): алгоритмы, TF, QoS, плагины, оборудование. Изучите и потренируйтесь объяснять; код не доказывает личное понимание |
| Срок: три календарных дня | Организационное условие | Передайте репозиторий/архив и видео до установленного работодателем срока; автоматическая отправка работодателю не выполняется |

Шкала содержит **11 основных баллов**, порог — 7, а также **три бонусных вопроса без явно указанных баллов**. Таблица сопоставляет каждый пункт с доказательствами; она не прогнозирует оценку работодателя. Указанный по имени GPS-плагин Classic — единственная явно раскрытая замена, связанная с выбранной платформой.
